# AERIS 無人機群飛動畫設計工作室

**[立即試用公開 Demo](https://xc1974.github.io/aeris-drone-studio/)** · **[GitHub 原始碼](https://github.com/xc1974/aeris-drone-studio)**

公開 Demo 不需要帳戶。每位訪客的設計只存在自己的瀏覽器，請用 JSON 匯出備份；適合在桌面版 Chrome／Edge 體驗，MP4 支援依瀏覽器編碼能力檢測。

`main` 更新時，GitHub Actions 會先執行所有測試與正式建置，成功後部署至 GitHub Pages。Pull request 僅執行測試與建置，不發布。

可在本機運行的完整 React + TypeScript + Vite + Three.js + Zustand 網頁 MVP。所有設計、獨立燈光、影片編碼與儲存都在瀏覽器完成，沒有後端或付費 API。

## 安裝與啟動

需要 Node.js 22.12 以上及 npm。在這個資料夾開啟終端機：

```powershell
npm ci
npm run dev
```

開啟終端機印出的網址，預設為 http://127.0.0.1:5173/ 。不要直接雙擊 index.html。第一次安裝需網路，安裝完成後不需要外部 API 或遠端字型。

```powershell
npm test
npm run build
```

建置結果在 `dist/`，可由任何靜態 HTTP 伺服器提供。MP4 編碼需要支援 WebCodecs 的安全環境（localhost 或 HTTPS），程式會實際檢查所選規格的 H.264 支援。

## 檔案結構與架構

```text
drone-studio/
  index.html
  package.json / package-lock.json
  tsconfig.json / vite.config.ts
  src/
    main.tsx
    core/
      types.ts       專案、無人機、燈光、群組、鏡頭資料型別
      formations.ts  六種精確數量的隊形產生器
      engine.ts      秒數時鐘、位置與獨立燈光插值、空間分格距離檢查
      effects.ts     將效果烘焙為每架獨立燈光影格
      demo.ts        100 架、三個隊形、十色與獨立燈光示範
      io.ts          完整 JSON 驗證、匯入、下載
      video.ts       確認 H.264 支援、逐格渲染、MP4 編碼與取消
      core.test.ts   隊形、插值、驗證、效果與資料同步測試
    state/
      store.ts       編輯命令、選取、復原／重做
    scene/
      Scene.tsx      批次渲染、拖曳、光影、Bloom、相機與截圖
      api.ts         自由相機、鏡頭插值與影片渲染介面
      camera.test.ts 鏡頭、相容性與預覽區間測試
    ui/
      App.tsx / Sidebar.tsx / Inspector.tsx
      Timeline.tsx / VideoPanel.tsx / common.tsx / style.css
```

位置與燈光採用獨立軌道。場景直接由目前時間計算每架的位置／燈光，以 InstancedMesh 更新 GPU 資料；不將每架每影格的位置寫回 React state。React 僅更新編輯資料、低頻 UI 時間與效能資訊。位置與燈光都依穩定 ID 對應，不在播放時重新分配 ID。

## 開始操作

1. 第一次開啟是 100 架「方形 → 圓形 → 愛心」，按播放直接預覽。已有本機暫存則自動還原；右上操作說明可重新載入示範。
2. 左側可套用 1～500 架，並有 100／300／500 測試按鈕。新增鍵加入一架；垃圾桶刪除所選物件。
3. 點清單或 3D 球體選取，Shift／Ctrl 點選多選。清單顯示 ID、顏色與 Y 高度；滑鼠停留可查看 XYZ。
4. 點位置軌道菱形，再於右側修改位置。X、Y、Z 為公尺，Y 向上；相對位移／3D 箭頭會批次平移，絕對座標輸入則統一所選物件該軸座標。
5. 位置影格選取後可套用直線、網格、圓、螺旋、球面、愛心。中心、尺寸、間距及旋轉依隊形顯示；「隊形整體燈光」是另外明確寫入全部燈光影格的操作。
6. 在底部細軌拖曳播放頭，按「位置影格」擷取當時插值位置。點菱形後可改名稱、時間及插值，或刪除。
7. 暫停後，右側燈光電源、色盤／HEX、亮度會明確於播放頭時間新增／更新所選各架的燈光影格。只改指定屬性，多選不同值顯示「多個值」。
8. 燈光軌道僅展開所選第一架。點燈光菱形可修改時間、插值、複製到指定時間或刪除；在右側修改該時間的顏色、亮度及開關。
9. 以選取物件建立命名群組；點群組選取其成員，然後套用固定、淡入、淡出、閃爍、呼吸、多色漸變或跑馬燈。全選可作用於全部。跑馬燈以目前選取順序依延遲逐架開始。
10. 頂部儲存至瀏覽器、匯出 JSON；「開啟」匯入完整 JSON。PNG 下載目前 3D 視角，包含場景光影。

## 影片、光影與 Free cam

點工作區右上「影片／MP4」開啟影片面板：

- 即時調整發光暈染（Bloom）、曝光、月光陰影與輔助線。夜景包含星空、月光、地面材質與雙色場景燈光。
- 自由相機預設可拖曳旋轉、縮放及平移；開啟「自由飛行」後，先點場景，再用 WASD 前後左右、Q/E 升降、Shift 加速。焦點在輸入欄時不接管按鍵。
- 「目前 Free cam 視角」輸出固定鏡位；「自動 360° 環繞」沿全專案時間環繞一圈。
- 「自由相機影格路線」：移動播放頭，調整自由相機，點「記錄鏡頭」。至少記錄兩個不同時間可形成運鏡；相同時間更新鏡頭。鏡頭影格獨立於無人機位置／燈光，可刪除，並隨 JSON 保存。
- 以「即時預覽鏡頭與燈光」觀看選取區間。鏡頭影格之間採 ease-in-out；首尾之外維持端點鏡位。
- 選 720p／1080p，24／30／60 fps，設定開始及結束秒數。程式先檢查該規格 H.264 編碼支援，再啟用 MP4 按鈕。
- 「產生 MP4」逐格離線渲染，不依賴即時 FPS，也不受 UI 播放速度／循環影響。自動去除輔助網格、ID、軌跡、選取圈和拖曳器，保留場景與燈光。輸出完在面板播放並下載真正的 H.264 MP4。
- 有進度與取消；完成或失敗會還原原本相機、解析度及時間。影片沒有音軌。

影片使用 Mediabunny 與瀏覽器 WebCodecs。支援檢測依官方介面實作：[編碼能力查詢](https://mediabunny.dev/guide/supported-formats-and-codecs)、[MP4 與 CanvasSource](https://mediabunny.dev/guide/writing-media-files)。不會把 WebM 改副檔名假裝 MP4。

## 資料規則

- 新增無人機使用新的唯一 ID，在**所有**位置影格加入相同待命座標，預設青色／開啟／100%，燈光軌道為空。原本無人機資料不變。
- 減少總數刪除清單尾端；刪除選取移除所選 ID。同時清理各位置影格、群組及歷史效果成員，該機獨立燈光隨之刪除。
- 編輯位置只寫入已選取的位置影格。拖曳播放頭或開始播放會取消位置影格選取並停用位置編輯；新增位置影格是明確操作。
- 每架 `light` 是預設燈光，`lights` 是獨立時間軌道。第一個燈光影格之前用預設值；最後之後保持最後值。開關在到達影格時瞬間切換，淡入淡出透過亮度完成，關燈保留色碼。
- 插值方式屬於起點影格，決定往下一影格的過渡。位置支援 linear／smooth；燈光另有 step。
- 效果寫成各架影格並保存效果參數／成員作為套用紀錄。效果只在套用時烘焙，不在播放時另行覆蓋，所以沒有群組優先順序。手動修改烘焙後影格是有效的最終結果，歷史效果紀錄不會重新套用。
- 同一軌道時間不可重複。縮短總長時若會裁掉位置、燈光、鏡頭或效果，會拒絕操作並顯示原因；請先調整／刪除超出範圍的資料。
- JSON `version: 1` 包含穩定 ID、位置、預設／各架獨立燈光、插值、群組、效果、動畫、場景、鏡頭與光影。匯入驗證所有欄位、數值範圍、引用與時間排序；舊 v1 缺少新增的光影／鏡頭欄位會補預設。
- 自動暫存延遲 700 ms；保留 40 次復原，Ctrl+Z／Ctrl+Shift+Z。復原與重做不包含播放頭／自由相機的即時操作。

## 驗證與限制

測試覆蓋六種隊形在 1／10／100／300／500 架的精確數量與有限座標、線性／平滑／step 插值、首尾行為、獨立燈光、JSON 完整往返與錯誤資料拒絕、增刪同步、效果、鏡頭與預覽結束。

瀏覽器實測包含本機場景渲染、播放、100／300／500 數量切換、選取與影格切換、MP4 支援檢查，以及 **1280×720、30 fps、2 秒 H.264 MP4** 輸出。輸出影片的瀏覽器解碼結果：duration=2、videoWidth=1280、videoHeight=720、readyState=4、error=null。1080p／60 fps 有規格檢測與輸出路徑，未逐一做長片驗證。

已知限制：

- 最多 500 架、600 秒、1000 個位置／鏡頭影格、每架最多 10000 燈光影格，全專案最多 100000 燈光影格；JSON 30 MB 上限。
- 間距檢查為 10 Hz 離散取樣與空間分格，非連續避碰檢查、非真實飛行安全認證。密集重疊時仍可能退化為平方級配對；關閉陰影、減少 Bloom 可降低渲染負擔。
- FPS 依設備、解析度、光影、編號與軌跡而變化，不保證固定值；場景顯示實測 FPS 和距離檢查耗時。
- 3D 編號只顯示前 100 架；清單保留全部。桌面介面最小寬 980 px，小螢幕可水平捲動；未提供手機觸控專用編輯器。
- 光影是藝術化即時近似，並非光度學或飛行物理模型。每架以自身發光球呈現，沒有建立數百盞實體照明光源；地面使用場景燈光與月光陰影。
- MP4 需要瀏覽器提供 H.264 編碼，並非所有瀏覽器／作業系統可輸出。影片保存在記憶體，長片／1080p60 可能耗費較多記憶體和時間；頁面需保持開啟。檔案下載取決於瀏覽器設定。
- 暫存容量受瀏覽器限制，大專案請匯出 JSON。沒有多人協作、後端帳戶、文字隊形、目標最佳分配、實體控制或飛行動力學；這些屬後續擴充。
- 初始 Three.js 主程式較大，Vite 建置可能出現 chunk 大小提示；不影響建置成功。
